# Expense Tracker

A full-stack expense management web application built with Python and Flask.

The project is being developed to practise the complete software-development lifecycle, including frontend development, backend development, database management, testing, version control, deployment and maintenance.

## Current Features

- Modular Flask application structure
- Reusable HTML templates
- Responsive frontend design
- Expense summary landing page

## Planned Features

- User registration and login
- Secure password storage
- Income and expense management
- Transaction categories
- Monthly dashboard
- Search and filtering
- PostgreSQL database
- Automated testing
- Live deployment

## Technology Stack

- Python
- Flask
- HTML
- CSS
- Jinja
- Git and GitHub
- PostgreSQL
- Render
